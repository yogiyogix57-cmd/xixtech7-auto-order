# XIXTECH7 AUTO ORDER

Modern, responsive landing page untuk layanan digital XIXTECH7 dengan order flow via WhatsApp.

## Fitur
- Dark mode premium dengan lime accent
- Responsive untuk mobile, tablet, dan desktop
- Service cards, statistik, proses order, dan FAQ accordion
- Modal order dengan redirect otomatis ke WhatsApp
- Tanpa framework dan tanpa dependency — bisa langsung dibuka di browser

## Menjalankan lokal
Buka `index.html` di browser, atau gunakan extension Live Server.

## Konfigurasi WhatsApp
Edit `WHATSAPP_NUMBER` di `script.js` menggunakan nomor WhatsApp bisnis dengan format kode negara tanpa tanda `+` atau spasi.

Contoh: `6281234567890`
